# Project_Smart-ParkingSmart Parking System

A console-based Smart Parking System developed in C++ using Object-Oriented Programming and Data Structures concepts. The project manages vehicle parking, slot allocation, entry/exit tracking, sorting, searching, and navigation features.

Features
Park and vacate vehicles
Manage Car, Bike, and Truck parking
Slot compatibility checking
Sort slots and vehicles
Entry/Exit logging
Undo parking operation
Exit queue management
Floor-wise parking management
Best available slot suggestion
Fast vehicle lookup using hashing
License plate pattern matching
Shortest path navigation using BFS
